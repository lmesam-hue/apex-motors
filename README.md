
  # Apex Motors - Concesionario de Lujo

  Aplicación web para concesionario de vehículos de lujo con landing page, sistema de autenticación y panel de administración.

  ## Stack

  - React 18 + Vite 6
  - Tailwind CSS v4
  - shadcn/ui + MUI
  - React Router v7

  ## Comandos

  ```bash
  npm install
  npm run dev
  npm run build
  ```
